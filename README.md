# Factory Manager — مدير المصنع

تطبيق ويب عربي RTL لإدارة المصنع، يعمل كتطبيق PWA. يشمل الحسابات، العملاء والموردين، الفواتير والمرتجعات، السندات، المخزون، أوامر الإنتاج، التقارير والطباعة.

## البنية
- الواجهة: `index.html`, `css/style.css`, `js/app.js`.
- تسجيل الدخول: Supabase Auth في `auth.html`, `js/auth.js`.
- مزامنة البيانات: `js/cloud-sync.js`.
- `public.factory_state` تحفظ نسخة كاملة من حالة التطبيق للمدير.
- حماية البيانات عبر RLS وسياسات صلاحيات حسب ملف الموظف.

## ملفات Supabase
- `supabase/schema.sql`: مخطط الأساس الذي تم تطبيقه على المشروع قبل ربط سجل migrations.
- `supabase/migrations/20261107080100_harden_auth_rls_20261107.sql`: تشديد تسجيل الدخول وRLS.
- `supabase/migrations/20261107081648_enforce_employee_permissions_20261107.sql`: صلاحيات الموظفين على مستوى قاعدة البيانات.
- `supabase/migrations/20261107090901_20261107111000_atomic_invoice_sync.sql`: مزامنة الفواتير وبنودها داخل معاملة واحدة مع كشف تعارض الإصدارات.
- `supabase/migrations/20261107090923_sync_invoice_delete_alias_fix.sql`: تصحيح مرجع حذف البنود داخل دالة المزامنة.
- `supabase/legacy/`: نسخة تاريخية من migration الأساس؛ ليست ضمن مسار migrations النشط.
- `supabase/functions/create-employee-account/index.ts`: إنشاء حسابات الفريق.

## ملاحظات تشغيلية
- استخدم مفتاح `anon` أو `publishable` العام في المتصفح فقط. لا تضع مفتاح `service_role` أو أي Secret في ملفات الواجهة.
- إنشاء الحسابات متاح من حساب المدير فقط عبر Edge Function؛ شاشة الدخول لا تتيح التسجيل الذاتي.
- في إعداد جديد: أنشئ أول مستخدم Auth من لوحة Supabase قبل تطبيق migration التدعيم؛ إذا كان هو المستخدم الوحيد، ترفعه migration إلى مدير النظام.
- حماية كلمات المرور المسربة ما زالت تحتاج تفعيلها من إعدادات Supabase Auth.
- الاتصال الحي مثبت على مشروع Supabase الإنتاجي `yvrislcbbhtruwdnuooz`. لا تستخدم إعدادات QA في نسخة الإنتاج.
- أثناء الاتصال بالإنترنت، قاعدة البيانات هي مصدر الحقيقة؛ كل حفظ يرسل السجلات المتغيرة فقط. التخزين المحلي وطابور التعديلات يُستخدمان عند انقطاع الإنترنت فقط، ثم يُفرغان بعد نجاح الرفع.
- بيانات الدخول للموظفين تستخدم اسم مستخدم فقط في واجهة البرنامج؛ يُنشأ عنوان داخلي اصطناعي لخدمة Supabase Auth، ويُطلب تغيير كلمة المرور المؤقتة عند أول دخول.
- استيراد/تصدير نسخة Excel الكاملة يشمل كل قوائم المصنع وإعداداته. قوالب Excel المنفصلة تدعم الأصناف والعملاء والموردين.
- آخر تحديث للواجهة: تحسين شاشة التحميل وتسجيل الدخول، القائمة الجانبية للموبايل، الشريط العلوي، وكاش التطبيق `factory-v14`.
- تم اجتياز 239 اختبارًا آليًا وبناء Vite. اختبارات الدخول الفعلي بحسابات الإنتاج وجلسة متزامنة على جهازين تظل اختبار قبول منفصلًا.


## سجل Manager.io التاريخي
- يضيف زر **سجل Manager.io** شاشة قراءة فقط متصلة بجداول الاستيراد المنظمة في Supabase Production.
- يعرض العملاء والموردين، الأصناف وأرصدة كل مخزن بصورة منفصلة، الفواتير والمرتجعات، السندات، أوامر الإنتاج، ودليل الحسابات ودفتر الأستاذ.
- تحميل كل قسم يتم عند فتحه فقط، مع الاحتفاظ بالنتائج في ذاكرة الجلسة لتقليل الضغط على قاعدة البيانات.
- السجلات التاريخية لا تُحوّل تلقائيًا إلى معاملات قابلة للتعديل داخل النظام التشغيلي، ولا تُكتب فوقها.
