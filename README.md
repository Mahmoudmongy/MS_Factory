# Factory Manager — مدير المصنع (2.0.1)

تطبيق ويب ثابت (PWA) عربي RTL لإدارة المصنع: فواتير ومرتجعات، سندات، مخزون وباركود، أوامر إنتاج، تقارير، قوالب طباعة، استيراد وتصدير.

## البنية الحالية

- الواجهة الأساسية: `index.html` و`css/style.css` و`js/app.js`.
- تسجيل الدخول: Supabase Auth من `auth.html` و`js/auth.js`.
- النسخة الاحتياطية الكاملة: جدول `public.factory_state` لحفظ حالة التطبيق كاملة بما فيها الحسابات والسندات والمرتجعات والإنتاج.
- جداول تفصيلية متزامنة: العملاء والموردون والفواتير وبنودها والمنتجات وغيرها.
- سياسات RLS تقيد بيانات المصنع بالمستخدم المالك وحسابات فريقه. ملف تعريف المستخدم لا يسمح بتعديل صلاحيات الإدارة أو الملكية من المتصفح.
- إنشاء حسابات الموظفين يتم عبر Edge Function محمية بالتحقق من JWT وبصلاحية مدير النظام.
- يعمل التطبيق كـ PWA؛ غلاف التطبيق يعمل offline، أما المزامنة فتحتاج إنترنت.

## التشغيل والاختبار

```bash
npm install
npx playwright install chromium
npm test
npm run serve
```

الاختبارات في `tests/run.js` تستخدم Chromium، وتشمل الحسابات والمخزون والإنتاج والصلاحيات والاستيراد والتصدير وPWA والموبايل.

## إعدادات الأمان

- مفتاح `sb_publishable_...` في المتصفح مفتاح عام مخصص للعميل، وليس مفتاح `service_role`.
- لا تضع مفتاح `service_role` أو أي Secret داخل ملفات الواجهة أو GitHub.
- وظيفة `create-employee-account` تعتمد على متغيرات Supabase البيئية المدمجة في Edge Functions.
- تفعيل حماية كلمات المرور المسربة ما زال مطلوبًا من إعدادات Auth في لوحة Supabase.

## ملاحظات تشغيلية

- النسخة الاحتياطية الكاملة هي المرجع لاستعادة حالة التطبيق. الاستعادة لا تستبدل بيانات محلية موجودة.
- المزامنة التفصيلية للجداول ما زالت طبقة توافق مع تصميم التطبيق الحالي، وليست بديلاً عن مراجعة كل عملية محاسبية على قاعدة البيانات.
- لا تعتبر صلاحيات إخفاء الشاشات في الواجهة بديلاً عن RLS؛ قواعد قاعدة البيانات هي حد الحماية الفعلي.
- توليد PDF وقراءة ملفات xlsx قد يحتاجان مكتبات خارجية واتصال إنترنت.
