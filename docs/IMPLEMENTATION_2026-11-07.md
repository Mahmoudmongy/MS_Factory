# تنفيذ تدعيم Supabase — 7 نوفمبر 2026

## النطاق
العمل على فرع `fix/supabase-auth-sync-hardening` من `main`. المشروع مستقل؛ لم تتم إضافة أي أدوار أو مسارات تشغيل للصنايعية أو رئيس العمال.

## تغييرات Supabase
- إضافة `profiles.is_admin` بصلاحية صريحة للمدير.
- حماية بيانات المصنع بسياسات RLS.
- إضافة `factory_state` للنسخة الكاملة من حالة التطبيق، وهي متاحة للمدير فقط لأنها تحتوي على بيانات كل الشاشات.
- تطبيق صلاحيات الموظفين على مستوى قاعدة البيانات، وليس إخفاء الواجهة فقط.
- جداول العملاء والموردين والمخزون والفواتير والإنتاج لها سياسات منفصلة حسب الصلاحية.
- حساب التقارير يتيح القراءة فقط، ولا يمنح الكتابة.
- إضافة فهارس للمفاتيح الأجنبية التي أبلغ عنها مستشار الأداء.
- وظيفة إنشاء حساب الموظف محمية بـ JWT وتتحقق من `profiles.is_admin` وتفرض قائمة صلاحيات معروفة. الوظيفة نشطة بالإصدار 4.

## تغييرات الواجهة
- ربط قائمة الشاشات وصلاحيات التعديل والحذف بملف المستخدم المحمّل من Supabase.
- إخفاء الصفحة إلى أن يتم التحقق من جلسة الدخول وملف المستخدم.
- مزامنة النسخة الكاملة مخصصة للمدير، بينما مزامنة الجداول التفصيلية تتبع صلاحيات الموظف.
